# This folder stores all application data files.
# They are created automatically when you run the app.
# 
# Files created at runtime:
#   users.txt       — login credentials (username,password,role)
#   donors.txt      — donor profiles
#   patients.txt    — patient profiles
#   inventory.txt   — blood bag stock
#   requests.txt    — blood requests and statuses
#   logs.txt        — activity audit trail
#
# DO NOT delete this folder. If deleted, recreate it (empty).
# The app will regenerate the .txt files on first use.
